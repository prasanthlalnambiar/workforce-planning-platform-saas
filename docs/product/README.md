# Product Source of Truth

This folder contains the product vision and planning-loop source documents for the Workforce Planning Platform SaaS.

Purpose: prevent future phases from being invented from code alone. Codex should read these documents before scoping Phase 5 or any later product module.

## Files

- `workforce-planning-vision.md` — converted from `workforce-planning-vision-revised.docx`.
- `lovable-phase-build-document.md` — phase-by-phase build plan and non-negotiable product rules.
- `master-loop-package-manifest.md` — index of the original `planning-agent-loop-v4-3-with-layer1.zip` source package and the key documents extracted from it.
- `codex-commercial-hardening-spec.md` — commercial hardening roadmap and work-package rules.

## Operating rule

Before building a new phase, read these documents, then produce a short implementation interpretation and phase boundary. Do not invent product semantics from README snippets alone.

## Phase boundary reminder

Phase 4 stops at locked Budget Baseline. Phase 5 should not begin until Phase 4.1 / WP0 quality gate passes externally.
